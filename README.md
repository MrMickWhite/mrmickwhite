# mrmickwhite

Web principal de la marca MrMickWhite — el portafolio de Miguel Montoya
(www.mrmickwhite.com). Desde aquí se presentan los proyectos y se enlazan los
sitios propios (Labs, Fly, E-Sports).

Es un sitio estático. La lista de proyectos se arma sola: `js/projects.js`
consulta en vivo los repositorios públicos de la organización en GitHub, así que
cada repo nuevo aparece sin tocar el código.

## Estructura

- `index.html` — la página (una sola, con scroll)
- `css/app.css` — estilos (estética de terminal)
- `js/common.js` — header, menú, datos de contacto, año automático
- `js/projects.js` — trae los repos desde la API de GitHub
- `js/main.js` — arranque
- `assets/` — logo, retrato y favicon
- `CNAME` — dominio (www.mrmickwhite.com)

Se despliega en Cloudflare Pages.
